# Slothdoku — For Haley (V6)

Upload all files in this folder directly to the root of your GitHub repository (including `index.html`, `puzzles.js`, `sw.js`, the icons, and the manifest). Enable GitHub Pages at Settings > Pages > Deploy from a branch > main > /(root).

## Controls
- Single tap: toggle a white X on a leaf (brief delay to distinguish from double tap).
- Swipe: mark multiple leaves with white Xs.
- Double tap: place a sloth; incorrect guesses show a temporary red X and use one of four leaves.
- Three hints per puzzle; no timer, no place/mark/undo/erase mode buttons.

## Included
- First-launch editable name and illustrated animal/frame selection, no prefilled name.
- Custom SVG illustrated animals and decorative full-avatar frames (no emoji characters in the game UI).
- Leaf Garden board with 2.5D styling, animated sloth faces, original pastel themes.
- Saved progress, puzzle bank, scores, four lives, hints, win/lose screens, quotes, love notes, achievements.
- Theme-specific generated melodies, mute and volume sliders, installable PWA.

## Known limitations
- This is a browser-based game, not a native App Store app. iOS does not expose its physical Silent switch reliably to web apps.
- Animal artwork is vector-styled 2.5D, not fully rendered 3D character animation. Motion is CSS/SVG-based.
- The included finite puzzle bank can eventually repeat. Daily Challenge is a labeled preview, not a scheduled daily puzzle yet.
- This release has not been tested on a physical iPhone. Please playtest touch behavior before gifting.
